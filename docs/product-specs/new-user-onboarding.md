# Product Spec: Expert Onboarding

**Status**: Shipped

## User Story

As an expert, I want to create a professional profile in under 5 minutes so I can start receiving **meetup** requests from players on the network.

## Flow

1. **Social Links**: Enter LinkedIn, Twitter/X, GitHub, personal website
2. **Domains**: Select areas of expertise (up to 5)
3. **Session Preferences**: Choose online/offline/both, set pricing per hour, currency
4. **Availability**: Set weekly schedule (recurring time ranges per day)
5. **Stripe KYC**: Connect Stripe account for payouts
6. **AI Generation**: System generates bio, tagline, services, and profile image from social data
7. **Service PDF**: Upload a service-introduction PDF before publishing (drafts may exist without it)
8. **Overview**: Inspect generated profile, edit as needed (onboarding step key may still be `PREVIEW` in schema)
9. **Publish**: Go live on the platform

## Requirements

- AI-generated content should be editable before publishing
- Profile image generated by AI (not user-uploaded) to ensure quality
- Stripe KYC must be completed before receiving paid meetups
- Weekly schedule supports multiple time ranges per day
- All steps accessible from both web and WeChat Mini Program
- Service-introduction PDF is required before the profile can be published

## Acceptance Criteria

- [ ] Expert can complete onboarding in < 5 minutes
- [ ] AI-generated bio is professional and accurate
- [ ] Expert can keep a draft profile without a PDF
- [ ] Expert cannot publish without a service-introduction PDF
- [ ] Profile appears in discover list after publishing
- [ ] Expert receives notification when a meetup is scheduled
